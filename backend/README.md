# Bclick Admin UI

A standalone, UI-only administration dashboard prototype built with React, Vite, Tailwind CSS, and shadcn/ui-style primitives.

## Run locally

From the repository root:

- `pnpm --filter backend dev` — open the admin dashboard at `http://localhost:5174`
- `pnpm --filter backend build` — build the admin UI

## Prototype boundary

All users, promotions, bonuses, games, transactions, analytics, and settings are local demonstration data. Forms and status controls are interface previews only. No API, database, authentication, financial operation, or backend business logic is connected.
