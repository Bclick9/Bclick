## Open gates that control the next work

- **Q-005 — P0, Open:** PR #94 route coverage and PR #95 stable-slug/category-ordering coverage are merged. The technical proposal separates BigBang's singular source category fields from Bclick's canonical `categories[]`. PR #100 adds Migration 009 with aliases for the 59 exact curated `GAMES[]` slugs, a sync-time unique exact title/provider binder, and by-slug handling that returns a safe 404 for unmatched aliases and 409 for ambiguous ones. The code is additive: a green CI run or merge does not close Q-005 or authorize applying the migration to a target database or cutting over the frontend. Q-005 stays open pending owner acceptance, same-key/same-scope evidence or vendor explanation for 3,802 vs 3,639, and written Standard/Premium ID-uniqueness evidence or a tier-inclusive design. No frontend cutover/Premium import is authorized.
- **Q-006 — P0, Open (partially evidenced):** `docs/notes/2026-10-22-Q006-provider-spec-review.md` now records the public WinHouse docs review alongside the pinned spec and support-supplied test vectors. Current evidence verifies the ordinary BigBang bet/win body HMAC, raw-body HMAC, and WinHouse bet/win HMAC; these are contract fixtures, not wallet-handler tests. Open items are BigBang zero-round-close, per-event header requirements, replay/conflicting payload and paired refusal vectors; WinHouse cashout/cancel/refund/out-of-order event semantics and related transaction mapping; plus recorded Owner/provider acceptance. No wallet implementation is enabled.
- **Q-010 — P0, Open:** ledger lock/concurrency and normative idempotency scope, including same/different-payload replay and posting-service tests.
- **Q-011 — P0, Open:** isolated base+WAL restore, integrity checks, independent alert evidence and measured RPO/RTO. No restore result is assumed.
- **Q-013 — P0, Open:** CSP/frame/host-header policy and staging evidence for player/admin/provider iframe flows.
- **Q-020 — P0, Open:** runtime contract evidence for each implemented route, alongside static OpenAPI checks. A CI fixture for an unimplemented or unexercised operation does not close this gate.
- **Q-009 — Owner decision accepted; PR #99 merged:** TND uses `0.01 TND = 10 millimes`, with no true third fractional digit. The shared money exponent is TND=2, wallet/API examples were updated, and guarded Migration 008 changes the database exponent from 3 to 2 only when no TND ledger entries exist and all projected TND balances are zero. The parser rejects values such as `12.345` rather than rounding. Migration 008 has not been run against any target database; keep the target migration/release gate separate and confirm the target's preconditions on an approved non-production target before any execution. Real-money routing remains blocked by Q-006, Q-010, Q-011 and other release gates.
